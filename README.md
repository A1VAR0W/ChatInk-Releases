# ChatInk Releases

Este repositorio público contiene exclusivamente los binarios oficiales y los metadatos de actualización de ChatInk. No contiene código fuente, configuración del servidor, credenciales ni secretos.

## Estado actual

Todavía no hay una versión pública publicada.

Las versiones estables publicarán un APK Android, un IPA para SideStore/AltStore y un archivo `SHA256SUMS` para verificar cada descarga.

## SideStore / AltStore

Cuando exista la primera versión, añade esta fuente en SideStore o AltStore:

```text
https://raw.githubusercontent.com/A1VAR0W/ChatInk-Releases/main/sidestore-source.json
```
